# 뉴스 스코어링 실무 활용과 기법

## 문제 정의

앞선 두 노트([[뉴스 감성지수 작성 방법론]], [[LLM 기반 뉴스 감성분석 파이프라인]])가 **"어떻게 만드는가"**를 다뤘다면, 이 노트는 **"실제로 어떻게 쓰는가"**를 다룬다.

## Part 1. 누가, 왜 쓰는가

| 주체 | 목적 | 사례 |
|------|------|------|
| 헤지펀드 퀀트 | 단기 알파 | 뉴스 발표 직후 수분~수시간 진입 |
| 원자재 트레이딩 하우스 | 수급·리스크 | WASDE 이후 심리 모니터링 |
| 자산운용사 | 중장기 테마 | ESG·에너지 전환 누적 |
| **기업 조달 부서** | **구매 타이밍·헤지** | **대상 같은 수요기업의 매수 시점 결정** |
| 리스크 관리 | 이벤트 조기 경보 | 팜유 수출금지, 기상 재난 |

> [!NOTE] 본 프로젝트의 위치
> <mark style="background: #FFF3A3A6;">대상(Daesang)을 위한 조달/구매 의사결정 지원</mark>. 구매 타이밍 최적화 + 이벤트 리스크 조기 경보 + 중기 가격 전망 보강.

## Part 2. 주요 활용 방식

### 2.1 알파 시그널 (Alpha = 시장 초과 수익)

**핵심**: 뉴스 감성이 가격을 선행한다면 매매 시그널로 활용.

전략 유형:
- **모멘텀**: 감성 상승 추세 → 롱
- **리버전**: 극단값 → 반대 베팅 (과민 반응 가설)
- **쇼크**: ±3σ 이탈 → 단기 진입

**대표 연구**:
- Tetlock (2007): WSJ 부정 어조 → 다음날 시장 수익 예측
- Heston & Sinha (2017): 뉴스 감성이 1~13주 수익률 예측
- Borovkova (2015): 원유·농산물 뉴스 감성과 선물가격

### 2.2 리스크 관리
- VaR(Value at Risk, 손실 한도) 보정: 감성 변동성 높을 때 보수화
- 포지션 사이징: 쇼크 전후 축소
- 상관 구조 감지: 평소 무관한 자산이 동일 뉴스에 반응 → 위기 징후

### 2.3 이벤트 드리븐
1. 이벤트 전: 컨센서스(시장 예상치) 수집
2. 발표: 실제 vs 컨센서스
3. 스코어링: 발표 후 1시간 내 뉴스의 집합적 해석
4. 시그널: "시장이 이를 얼마나 강하게 해석하는가"

### 2.4 조달·구매 의사결정 (본 프로젝트)
- 구매 타이밍: 감성 부정(공급 풍부) + 가격 저점 → 대량 구매
- 헤지 비율: 감성 급변기 → 헤지 비중 증가
- 장기 계약: 구조적 뉴스 흐름으로 공급처 협상

## Part 3. 기술 기법

### 3.1 NLP 기초
- **Tokenization, Lemmatization**: "rising, rose, risen" → "rise"
- **NER (개체명 인식)**: USDA, Brazil, $50/bbl
- **문서 표현**: BoW → TF-IDF → Word2Vec → BERT → Sentence Transformers

### 3.2 감성 분석

**사전 기반**:
- **LM (Loughran-McDonald) 사전**: 금융 특화. 일반 사전에서 "liability"는 부정이지만 금융에서는 중립
- **VADER**: SNS·뉴스 공용
- **AFINN**: 단순 가중치

**ML/DL**:
- Naive Bayes, SVM (베이스라인)
- **FinBERT**: Financial PhraseBank로 fine-tuning, 금융 뉴스 3분류
- Twitter-RoBERTa

**LLM**:
- Zero-shot, Few-shot, Fine-tuning
- **RAG**: 과거 유사 사건 검색 후 참고하여 스코어링

### 3.3 주제·이벤트 추출
- **LDA** (고전 토픽 모델링)
- **BERTopic** (BERT 임베딩 + 클러스터링, 현재 표준)
- **Open IE**, LLM 프롬프트 기반 이벤트 추출

### 3.4 집계 기법

**시간 감쇠 가중**:
```
score_t = Σ exp(-λ(t - t_i)) × final_score_i
```
λ는 뉴스 임팩트 지속 시간에 따라 조정.

**소스 가중 평균**, **극단값 피처**, **변화율·가속도 피처** 등.

### 3.5 품질 검증
- **Pearson/Spearman 상관** (시차별 lagged correlation)
- **Granger Causality Test**: "A가 B를 예측하는 데 도움이 되는가" 통계 검정
- **Event Study**: 이벤트 전후 초과 수익률(abnormal return) 분석
- **백테스트**: Sharpe, max drawdown, hit rate

### 3.6 고급 기법
- **멀티모달**: 텍스트 + 차트 이미지 + SNS + 위성 이미지
- **Cross-Asset Sentiment**: 팜유·대두·원유·USD·바이오디젤 상대 감성
- **Sentiment Network**: 개체 관계 그래프 변화 감지
- **Causal Inference** (Double ML 등): "뉴스가 가격을 움직이는가 vs 반대인가"

## Part 4. 실무 함정

> [!WARNING] 데이터 함정
> - **Look-ahead bias**: 미래 뉴스를 과거 피처로 사용
> - **Survivorship bias**: 폐간 매체의 과거 뉴스 누락
> - **Sample selection**: 특정 매체 편중
> - **Publication lag**: 발행 시점 ≠ 이벤트 발생 시점

> [!WARNING] 모델 함정
> - Overfitting to news (뉴스 피처 과적합)
> - Sentiment ≠ Price (톤과 가격이 늘 일치하지 않음)
> - Domain drift (시장 언어 변화)
> - Source bias (매체 논조 편향)

> [!WARNING] 해석 함정
> - **상관을 인과로 오해**: 같은 요인이 둘 다 움직였을 수 있음
> - 일별 평균 집계는 극단 이벤트를 희석
> - 단기 부정 ≠ 장기 부정

## Part 6. 본 프로젝트 권장 활용안

**단기 PoC**: LLM 기반 스코어링, 일별 감성 1~3개 피처, 성능 기여도 검증
**중기 운영**: LLM + 캐싱 + 배치, 카테고리별 감성, 월 단위 골드셋 재검증
**장기 고도화**: 이벤트 추출 + 네트워크 + 인과추론, "구매 추천" 시그널, 실제 조달 P&L과 연결

## 맺음말
<mark style="background: #FFF3A3A6;">뉴스 스코어링은 단순 NLP 문제가 아니라 시장 구조와 도메인 지식을 녹여내는 작업이다.</mark> 최첨단 모델을 써도 "대두유 시장에서 이 뉴스가 왜 중요한가"라는 도메인 이해가 없으면 노이즈만 쌓인다.
