## 왜 중요한가
대두유 가격은 WASDE 발표, 브라질 작황, 바이오디젤 정책 등 **뉴스 이벤트에 민감하게 반응**한다. 뉴스 데이터를 체계적으로 수집·스코어링하지 않으면 가격 변동의 핵심 신호를 놓친다.

## 5계층 파이프라인
<mark style="background: #FFF3A3A6;">뉴스 소스 → 수집(Ingestion) → 전처리 → NLP 스코어링 → 저장/모델 통합</mark>

| 계층   | 역할                 | 핵심 도구                                  |
| ---- | ------------------ | -------------------------------------- |
| 소스   | **RSS, API, 웹페이지** | **Fastmarkets**, **USDA**, **Reuters** |
| 수집   | **스케줄 기반 수집**      | Airflow DAG, feedparser                |
| 전처리  | **본문 추출, 중복 제거**   | newspaper3k, MinHash                   |
| 스코어링 | **감성/임팩트 산출**      | **FinBERT**, **LLM**                   |
| 저장   | **시계열 피처화**        | DB + master_daily 조인                   |



## 소스 우선순위
비용 대비 커버리지 기준 권장 조합:
- **Fastmarkets / AgriCensus** — 대두유 전문 (유료, 심층)
- **USDA RSS** — 공식 발표(WASDE 등), 무료
- **Reuters** — 속보성
- **AgWeb RSS** — 무료 보완

> [!NOTE]
> Oil World는 오일씨드 분야 최고 권위지만 구독료가 비싸다. POC 단계에서는 USDA + Reuters + AgWeb 무료 조합으로 시작 가능.

## 수집 방식
**RSS + newspaper3k** 조합이 현실적 기본값:
- RSS로 헤드라인/링크 수집
- newspaper3k로 본문 파싱
- 페이월 기사는 **헤드라인 모드**로 분리 처리

## 아키텍처 패턴
- **기본**: Airflow 기반 **일별 배치 DAG** (일별 종가 예측에 적합)
- **예외**: WASDE 발표일 등 고임팩트 이벤트는 실시간(Kafka) 고려

> [!NOTE] DAG란
> Directed Acyclic Graph. 작업 간 실행 순서와 의존 관계를 정의하는 구조.
