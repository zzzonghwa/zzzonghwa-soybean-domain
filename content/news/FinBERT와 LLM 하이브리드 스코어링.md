## 문제 정의
모든 뉴스를 LLM으로 돌리면 비용이 폭발하고, 전부 FinBERT로 돌리면 고임팩트 이벤트의 뉘앙스를 놓친다.

## 하이브리드 전략
<mark style="background: #FFF3A3A6;">역할 분리: FinBERT(속도/대량) + LLM(정확도/고임팩트)</mark>

| 구분  | FinBERT    | LLM (GPT/Claude)       |
| --- | ---------- | ---------------------- |
| 대상  | 일반 헤드라인 대량 | WASDE, NOPA 등 고임팩트 이벤트 |
| 장점  | 빠르고 저렴     | 맥락·뉘앙스 이해              |
| 단점  | 금융 일반 감성만  | 비용, 지연                 |

> [!NOTE]
> FinBERT는 ProsusAI가 공개한 금융 뉴스 특화 BERT. 범용 BERT 대비 금융 용어에 강하다.

## 이벤트 기반 가중치 (경험적 추정 — 검증 필요)
고임팩트 이벤트에는 감성 점수에 배수를 곱해 신호 강도를 키운다.

| 이벤트          | 가중치 |
| ------------ | --- |
| WASDE 발표     | ×5  |
| NOPA 크러시 데이터 | ×3  |
| 주간 수출 판매     | ×2  |
| 일반 뉴스        | ×1  |

> [!WARNING]
> 위 배수는 경험적 추정값이다. 실제 데이터로 회귀 분석해 검증해야 한다.
