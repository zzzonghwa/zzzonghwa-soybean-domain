# 착유량과 대두유 가격의 관계: 같은 행동, 반대 결과

## 먼저 알아야 할 것: 결합 생산
대두를 짜면 대두유(18%)와 대두박(73%)이 동시에 나온다. 이걸 따로 만들 수는 없다.
```
[대두 1부셸 = 약 27kg]
        │
        ▼  착유(crushing)
   ┌────┴────┐
   ▼         ▼
 대두유      대두박
 ~5kg       ~20kg
```

> [!NOTE] 목재소 비유
> 나무를 켜면 **판자**(주산물)와 **톱밥**(부산물)이 동시에 나온다. 판자를 더 만들려고 나무를 많이 켜면, 원하지 않아도 톱밥이 쏟아진다. **"둘 중 뭘 원해서 짜느냐"**에 따라 나머지 하나가 시장에 넘쳐 가격이 떨어진다.

## 핵심: "왜 짜는가?"에 따라 가격 방향이 달라진다

| 시기        | 착유량      | 대두유 가격               | 직관과 맞는가?       |
| --------- | -------- | -------------------- | -------------- |
| 2014~2019 | 꾸준히 증가   | 27~35센트/lb (약세)      | 맞음 (공급↑ → 가격↓) |
| 2021~2022 | 역대급 증가   | 50→**87센트/lb 사상 최고** | **안 맞음**       |
| 2023~2024 | 사상 최고 경신 | 40센트대로 하락            | 맞음             |
같은 "착유량 증가"인데 결과가 반대인 이유는 **동기(motivation)** 의 차이다.
## 두 가지 체제
![[Pasted image 20260406172502.png]]
### 체제 1: 박 중심 착유 (Crush for Meal) — 2014~2019
1. 대두박(사료) 수요 폭증 → 착유업체 가동률 올림
2. 대두유는 **원치 않는 부산물**로 함께 쏟아져 나옴
3. 대두유 수요(식용유)는 느리게 성장 → 공급 > 수요
4. **대두유 가격 하락**

### 체제 2: 기름 중심 착유 (Crush for Oil) — 2021~2022
1. [[바이오연료 정책과 대두유|바이오연료 정책]]이 대두유 수요를 구조적으로 끌어올림
2. 대두유 가격 ↑ → 착유업체가 **기름의 이윤** 때문에 가동률 올림
3. 공급이 늘지만 수요 증가가 공급 증가를 **초과**
4. **대두유 가격 유지/상승**
5. 대두박이 오히려 부산물화 → 박 가격 약세

### 외부 충격도 겹쳤다 (단일 원인이 아님)
2021~2022년을 "기름 중심 착유" 하나로 설명하면 **과도한 단순화**다. 동시에:
- 우크라이나 전쟁 → 해바라기유 공급 마비
- 인도네시아 팜유 수출 금지
- 코로나 이후 공급망 혼란

<mark style="background: #FFF3A3A6;">바이오연료 정책이 구조적 기반을 만들었고, 외부 공급 충격이 극단적 수준까지 밀어올렸다.</mark>
## 체제 전환은 왜 일어나는가: 정책이 결정한다

| 정책 변화                  | 체제 방향               |
| ---------------------- | ------------------- |
| RVO(의무 혼합량) 확대         | → Crush for Oil     |
| 블렌더스 크레딧 / 45Z 크레딧 활성화 | → Crush for Oil     |
| 폐식용유(UCO) 수입 급증        | → Crush for Meal 복귀 |
| 글로벌 대두박 수요 급증          | → Crush for Meal    |

### [[오일셰어 (Oil Share)]]: 지금 어떤 체제인지 확인하는 지표

Oil Share = 대두유 가치 ÷ (대두유 가치 + 대두박 가치) × 100%

역사적 범위: **25.8%**(2014.9) ~ **52.7%**(2022.5)

> [!WARNING]
> Oil Share는 체제의 "원인"이 아니라 **"결과"이자 "확인 지표"**다. Oil Share 자체가 유 가격의 함수이므로, "Oil Share가 높아서 유 가격이 올랐다"고 말하면 순환 논증이 된다.
## 실전 적용: [[NOPA (미국 유지종자 가공업 협회)|NOPA]] 착유 보고서 해석법
같은 착유량 서프라이즈라도 **체제에 따라 가격 반응이 다르다:**

| 착유량   | 대두유 재고 | 해석                          | 가격 반응 |
| ----- | ------ | --------------------------- | ----- |
| 예상 상회 | 예상 하회  | 많이 짰는데 재고 줄음 = **수요 매우 강함** | 상승    |
| 예상 상회 | 예상 상회  | 많이 짰고 재고도 쌓임 = **공급 과잉**    | 하락    |
| 예상 하회 | 예상 하회  | 덜 짰는데도 재고 줄음 = **극심한 수요**   | 강한 상승 |
| 예상 하회 | 예상 상회  | 덜 짰는데 재고 늘음 = **수요 약화**     | 하락    |

## 착유량 뉴스를 볼 때 물어야 할 3가지 질문
1. **지금 어떤 체제인가?** — Crush for Oil? Crush for Meal?
2. **착유량이 늘어난 만큼 수요도 늘었는가?** — 공급↑ > 수요↑ → 하락
3. **대두유 재고는 어떻게 변했는가?** — 착유량↑ + 재고↓ = 수요가 매우 강함

## 가설과 검증 상태

| 주장 | 근거 수준 |
|------|-----------|
| 결합 생산 구조 (유+박 동시 산출) | 물리적 사실 |
| 2014~2019 박 중심 착유 → 유 가격 약세 | 실증 데이터 |
| 2021~2022 유 중심 착유 → 유 가격 강세 | 실증 데이터 (단, 외부 충격과 분리 어려움) |
| 바이오연료 정책이 체제 전환의 핵심 원인 | 이론 + 정황 증거 |
