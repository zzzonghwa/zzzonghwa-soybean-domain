# 트레이딩 데스크의 역할 구분
## 왜 이게 중요한가
대두유 가격 예측은 "데이터 사이언티스트 한 명이 모델 돌리면 끝"이 아니다. <mark style="background: #FFF3A3A6;">실제 곡물 메이저(Cargill, ADM, Bunge)의 트레이딩 조직은 다학제 팀이 하나의 데스크를 지원하는 구조다.</mark>
## 실제 팀 구성 (Cargill TDA 기준)
Cargill의 **Trading Data Analytics(TDA)** 팀 채용 공고(2024-2025)를 보면 다음 직군이 한 팀으로 구성된다.

> [!NOTE] 카길(Cargill) 기업
> 카길(Cargill)은 ==1865년 설립된 미국 미네소타 기반의 세계 최대 비상장 농산물·식품 기업==으로, 전 세계 70개국에서 15만 5,000명 이상의 직원이 곡물 유통, 식품 원료, 동물 영양(사료), 산업 제품을 공급합니다. 세계 4대 곡물 메이저(ABCD) 중 하나로, 지속 가능한 방식으로 농부와 고객을 연결하며 식량 안보에 기여합니다.


| 직군                    | 핵심 역할                   |
| --------------------- | ----------------------- |
| `농업 전문가(Agronomist)`  | 작황 상태, 기후 리스크 해석        |
| `기상학자(Meteorologist)` | 엘니뇨·라니냐 → 수급 신호로 번역     |
| `경제학자(Economist)`     | 정책 변수, 거시 지표, 수요 탄력성 해석 |
| `통계학자(Statistician)`  | 모델 설계, 백테스트, 유의성 검정     |
| `데이터 사이언티스트(DS)`      | ML 예측 모델, 피처 엔지니어링      |
| `데이터 엔지니어(DE)`        | 데이터 파이프라인, ETL, 품질 관리   |

## 4가지 핵심 역할 비교
### 마켓 애널리스트 — "왜?"를 설명하는 사람
- 수급 보고서([[WASDE (세계 농산물 수급 전망)|WASDE]], [[NOPA (미국 유지종자 가공업 협회)|NOPA]]) 해석 및 시나리오 작성
- 수치 모델보다 **내러티브 생성**이 핵심
- 모델 결과를 검증하는 도메인 리뷰어 역할

### 데이터 사이언티스트 — "얼마나?"를 계산하는 사람
- ML 모델 설계·학습·배포
- [[피처 엔지니어링|피처 엔지니어링]]이 핵심 역량
- 애널리스트의 가설을 데이터로 검증하는 검증자

### 퀀트(Quantitative Analyst) — DS와 비슷하지만 다르다
- **퀀트**: 파생상품 프라이싱, VaR 등 리스크 수량화에 집중
- **DS**: 패턴 인식, 예측 정확도에 집중
- 2020년 이후 두 역할의 경계가 빠르게 흐려지는 추세

### 데이터 엔지니어 — 가장 먼저 필요하지만 자주 빠지는 역할
- <mark style="background: #FFF3A3A6;">파이프라인 없이는 모델이 존재할 수 없다</mark>
- 원자재 ETL은 일반 ETL과 다름: 배송 주기, 옵션 만기 캘린더, 단위 변환(부셸 → 톤) 등
- DS보다 DE가 **먼저** 필요한 경우가 많음

## 협업 워크플로우

| 단계 | 누가 | 무엇을 |
|------|------|--------|
| 1. 변수 발굴 | 애널리스트 | 핵심 변수 정의, 인과 가설 수립 |
| 2. 데이터 확보 | 데이터 엔지니어 | 파이프라인 구축, ETL, 품질 검증 |
| 3. 모델 구축 | 데이터 사이언티스트 | 피처 엔지니어링, 모델 학습 |
| 4. 도메인 검증 | 애널리스트 | 모델 결과에 통찰력 더해 최종 판단 |
| 5. 모니터링 | DS + DE + 애널리스트 | 성능 추적, [[모델 드리프트(Model Drift)|드리프트]] 감지 |

> [!NOTE] 이 프로젝트에 적용
> 현재 학습/설계 단계에서는 이 세 역할(애널리스트·DS·DE)을 순서대로 이해하는 것이 목표다. 지금은 **애널리스트 역할**(도메인 이해, 변수 발굴)에 집중하고 있다.
